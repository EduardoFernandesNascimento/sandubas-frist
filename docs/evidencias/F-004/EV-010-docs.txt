61:O token vale **5 minutos** por padrão. Para mudar, defina `JWT_EXPIRA_EM` antes de subir a API (aceita `30s`, `1m`, `2h`...):
65:JWT_EXPIRA_EM=1m npm start
68:No PowerShell: `$env:JWT_EXPIRA_EM="1m"; npm start`. Um valor curto ajuda a mostrar o passo 7 do roteiro.
73:- O token fica no `localStorage` do navegador. Isso foi **aceito para a demonstração**, porque é simples de mostrar e de inspecionar.
74:- Em produção, guardar o token num **cookie `httpOnly`** reduz o risco de roubo do token por XSS, já que o JavaScript da página não consegue ler esse cookie.
